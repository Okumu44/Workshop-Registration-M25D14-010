PROJECT DESCRIPTION

This project is a simple workshop registration page made using HTML, CSS and JavaScript.

The form allows a user to:
- Enter personal and contact details.
- Choose a workshop.
- Select a preferred date.
- Select between 1 and 4 seats.
- Confirm a practice password.
- Preview the registration after all required information is valid.

The project uses JavaScript to create the workshop choices and to validate the form before showing the registration result.

FILES

index.html
Contains the workshop registration form and page structure.

styles.css
Contains the page layout, colours, button styling and responsive design.

app.js
Creates the workshop choices, checks the passwords, validates the form and displays the registration result.

test-record.txt
Contains the testing checklist for valid and invalid registrations.

HOW TO RUN

1. Keep all the files in the same folder.
2. Open index.html in a web browser.
3. Fill in all required fields.
4. Choose a workshop from the Workshop dropdown.
5. Use an invented password with at least 10 characters.
6. Tick the agreement checkbox.
7. Click Preview registration.
